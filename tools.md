# Tools & Apps

Focus on free or freemium options that address common AuDHD friction: task initiation, time blindness, visual planning, sensory-friendly design, body doubling, and flexible routines.

## Top Picks by Problem (as of late 2026)

| Problem | Tools | Notes |
|---------|-------|-------|
| Getting started / task paralysis | Goblin Tools (Magic ToDo), Roomie Cafe, Focusmate | AI step breakdown; quiet or video body doubling |
| Time blindness | Time Timer, Llama Life, visual timers | Countdown makes time tangible |
| Visual daily planning | Tiimo, Structured, Thruday | Color blocks / timelines; designed with ND input |
| Phone distraction | Forest, Opal, one sec | App blockers with gentle friction |
| Focus / sound | Brain.fm, Endel, brown noise / ambient | Neural entrainment or adaptive soundscapes |
| Task breakdown & admin | Goblin Tools, Carly (AI agents), Todoist | Brain dump → steps; email/calendar automation |
| Routines | Tiimo, RoutineFlow, Focus Bear, meinsystem.app | Flexible structure without guilt |
| Sensory / regulation | FeelingsHelper tools, Balanced Mind app, Medito | Masking cost trackers, emotion wheels, free meditation |

## Other Notable Mentions

- **Goblin Tools**: Collection of small AI tools (Formalizer, Estimator, Compiler, etc.). Free on web.
- **Tiimo**: Visual planner co-designed with ADHD/autism experts.
- **Structured**: Timeline day view.
- **Roomie Cafe**: Quiet body doubling with no session limits on free tier.
- **SUPERHERO ADHD & AuDHD Tools**: Body doubling with a sidekick character.
- **Sprout / other AuDHD-specific apps**: Emphasis on sensory-friendly design, flexible routines, dopamine-friendly rewards, AI task breakdown.

Many mainstream productivity tools fail for AuDHD because they assume consistent executive function or punish broken streaks. Prefer tools that allow easy rescheduling and low sensory load.
